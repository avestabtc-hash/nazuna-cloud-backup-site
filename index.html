Nazuna Cloud Backup

A private, single-user backup and restore tool. It runs on the owner's own computer, uses rclone to move files to and from the owner's own Google Drive, and has no application server of its own.

What it does

  • Backup and restoration

    Copies selected local files into a folder in the owner's Google Drive and brings them back when a restore is needed. Transfers are started manually by the owner; there is no always-on background sync service.

  • SHA-256 integrity verification

    File integrity is checked with SHA-256 checksums computed locally on the owner's machine and compared between source and restored copies. Verification happens locally; it is not a server-side attestation from Google Drive.

  • Google Drive OAuth 2.0

    Access to Google Drive is granted through Google's standard OAuth 2.0 authorization flow. The resulting token is kept in the local rclone configuration on the owner's computer, never on this website.

  • Limited drive.file scope

    The only Google scope requested is drive.file, the per-file scope. It covers files this tool creates or files the owner explicitly opens with it. It does not grant access to the rest of the Drive.

  • Owner-controlled transfers

    The owner chooses which files are included, when a transfer runs, and which Drive folder is used. Nothing is uploaded without an explicitly started command.

  • No independent application server

    There is no backend, database, telemetry endpoint, or hosted account system. This site is static documentation; the utility itself is a local rclone configuration and workflow.

How a backup works

  1. The owner authorizes Google Drive access once through Google's OAuth 2.0 consent screen, with the drive.file scope.
  2. The owner runs an rclone command on their own machine to copy a chosen set of files into their own Google Drive.
  3. Restores run the same way in reverse. Local SHA-256 checksums are computed and compared to detect differences between the source and the restored copy.

Scope of this project. Nazuna Cloud Backup is a personal utility for its owner, not a publicly offered cloud service. This website does not collect data, host accounts, or accept file uploads. The Google OAuth consent screen and its verification are configured separately in Google Cloud Console by the owner.
