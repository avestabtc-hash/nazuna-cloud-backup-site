# Nazuna Cloud Backup - project site

Static documentation site for the personal rclone + Google Drive backup utility.

- `index.html` - homepage
- `privacy.html` - privacy policy for Google OAuth branding
- `styles.css` - shared styles

No frameworks, no build step, no backend, no analytics. Published with GitHub Pages from the `main` branch.

This repository contains documentation only. It contains no OAuth client secrets, rclone tokens, configuration files, or backup data.
